# ProView TV — releases

Installable builds of ProView TV for Android TV, Google TV and Fire TV. Source code is not published here.

**Latest APK:** https://github.com/gitzero-io/ProView-releases/releases/latest/download/ProView.apk

Install on Fire TV / Google TV with the Downloader app: enter the ProView code (or the link above), then allow Downloader to install unknown apps when asked.
